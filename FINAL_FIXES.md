# 💰 Price Comparison & Scenario Tool

## Completed Features
1.  **Comparison Mode Logic**:
    - **Sum Mode (1 item):** Shows the price/total of the selected item.
    - **Difference Mode (2+ items):** Automatically switches to showing the **Price Difference** (Spread: Max-Min).
    - **Smart PDF/Print:** "Print" and "Scenario PDF" now correctly show "Price Difference" (Red) when comparing multiple items, or "Total Estimate" (Green) when viewing a single quote.
    - **Sidebar Shortcut:** Added a "Scenario Builder" shortcut (Red Calculator Icon) to the right-side app bar for quick access.

2.  **Comparison Matrix (Compare Vehicles)**:
    - **Matrix View:** Side-by-side prices for all vehicle types.
    - **Difference Row:** Shows max-min spread in Red.
    - **Fixed Alignment:** Corrected "Difference (Max-Min)" text alignment in PDF.
    - **Dedicated Export:** Print and Matrix PDF.

3.  **Preview Modal**:
    - **On-Screen Invoice:** Shows summary for selected vehicle.
    - **Dedicated Export:** Print and Save PDF.

4.  **Live Pricing List ("View All" Modal)**:
    - **Restored Print Option:** Added "Print" button back.
    - **Fixed PDF Download:** Generates a proper PDF file.

5.  **PDF Archiving (File Manager)**:
    - **Automatic Saving:** All generated PDFs (Matrix, Scenario, Live List) are now automatically saved to the File Manager (Archive) upon download.

## How to Use
1.  **Build Scenario:** Select items.
2.  **Preview:** Click "Preview" -> "Save PDF" (Saved to Estimates folder).
3.  **Compare:** Click "Compare Vehicles" -> "Matrix PDF" (Saved to Estimates folder).
4.  **Full List:** Click "View All" -> "Download PDF" (Saved to Pricing folder) OR "Print".
