## How to Use:

### **Viewing All Media**:
1. Go to **Vehicle Gallery** page
2. Default view shows ALL photos/videos in a grid
3. Each tile shows:
   - Category badge (top-left corner)
   - Vehicle info (bottom)
   - Customer name (bottom)
   - Customer type badge

### **Uploading Photos**:
1. **List View**: Click "+ Add Media" next to any vehicle
2. Choose category (General, Before, After, Video)
3. Upload file or paste URL
4. Photos appear immediately in BOTH gallery and customer files

### **Finding Media**:
- Use search box to filter by customer name, vehicle, or VIN
- Click any photo to view full size
- Hover for View/Delete buttons (admins only)
